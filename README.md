# Bakery Custom

A simple HTML, CSS, and JavaScript bakery order portal.

## Project structure

```text
bakery-custom/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── script.js
├── assets/
│   └── images/
└── README.md
```

## Run locally

Open `index.html` in your browser.

You can also use a local static server if you prefer:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
